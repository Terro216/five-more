# Пилот 0.5: проверка на телефоне

Автоматические проверки не подтверждают доставку звука на конкретном телефоне.
До первого обычного утра пройди короткий сценарий ниже. Для обновления поверх
прежнего APK нужен тот же ключ подписи; удалять приложение и его данные для
проверки обновления не требуется.

## Короткий прогон

1. Установи 0.5 на Android 8+ arm64 или собери на iPhone с iOS 26+ и своей
   подписью. Открой прежний будильник: время, дни, название, сложность и лимит
   переносов должны сохраниться. Перемещение кнопки должно быть выключено.
2. Создай отдельный будильник через «Мягко». Открой «Проверка телефона», выдай
   разрешения по одному и запусти проверку через 20 секунд. Заблокируй экран,
   дождись звука, отключи звонок и отметь реальный результат. Повтори без сети;
   отдельно проверь отмену пробного звонка без изменения обычного расписания.
3. В ручных настройках выбери «Зеркальный текст», попробуй тренировку, затем
   назначь ближайший звонок. Введи неверную фразу, потом верную с другим
   регистром: ошибка должна оставить картинку и завершённые шаги. Повтори с
   «Кодом с картинки», выбрав латинскую раскладку. Проверь Enter и кнопку ответа.
4. При открытой клавиатуре увеличь шрифт и поверни телефон. Аварийное отключение
   должно оставаться доступным. На Android открытие задания само по себе
   не должно выключать звук; на iOS отдельно проверь системную Stop.
5. Включи «Кнопка переноса меняет место» и три переноса. Используй перенос:
   в следующий раз кнопка должна быть с другой стороны. Закрой и вновь открой
   приложение во время этого звонка — положение и остаток переносов должны
   сохраниться. В течение одного звонка и при нажатии кнопка неподвижна.
6. Выбери «С разгоном»: первое задание лёгкое, после переноса среднее, затем
   сложное. Следующий обычный подъём снова начинается с исходного уровня.
   В «Миксе» теперь шесть заданий, включая оба текстовых.

## Android: защита и перезагрузка

Открой «Проверка телефона» → «Надёжность и защита».

- Проверь батарею и настройки приложения. Если оболочка требует разрешения
  автозапуска, выдай его вручную. В режиме «Не беспокоить» разреши будильники
  в системных настройках звука.
- Нажми «Включить защиту от удаления». Сначала отмени запрос: статус должен
  остаться прежним. Затем повтори и подтверди системный запрос Android.
  Удаление должно требовать снятия статуса администратора. Само приложение
  не удаляй: отключи защиту через приложение и проверь фактический статус
  в системных настройках. Повтори отзыв статуса из системного раздела.
- Назначь ближайший звонок и перезагрузи телефон. Один раз дождись звонка после
  разблокирования; отдельный раз — не разблокируя телефон после загрузки.
  Проверь также перезагрузку во время переноса: оставшийся лимит не обнуляется.
- Если показана ошибка восстановления, верни необходимые разрешения и нажми
  «Повторить восстановление». Проверь и обычную кнопку «Восстановить
  расписание». Успешный ответ не заменяет последующего пробного звонка.

Защита от удаления действует, пока пользователь её не отключит. Она не делает
телефон невыключаемым. После принудительной остановки приложения нужно открыть
его и восстановить расписание; Android/iOS могут ограничивать доставку.

## Доступность и повторная попытка

Проверь TalkBack/VoiceOver, крупный шрифт, клавиатуру и смену ориентации. В
«Памяти» рисунок при доступной навигации должен оставаться до «Запомнил, начнём»,
включая повторный просмотр. Зеркало и код с картинки — визуальные задания:
скринридер не должен читать их ответ. Перед обычным использованием выбери
подходящий тип; аварийное отключение сохраняется и в визуальных заданиях.

Если система отказала в отключении после уже решённого задания, должно быть
доступно «Повторить отключение» без новой сессии в текущем экране. Длинная
ошибка прокручивается отдельно. Автоматические тесты подставляют такие отказы;
реальные ошибки системы и работа клавиатур проверяются отдельно.

## Журнал устройства

| Проверка | Результат |
|---|---|
| Модель телефона / версия ОС | Заполнить на устройстве |
| Версия / источник APK / подпись | 0.5.0; заполнить источник |
| Обновление без изменения прежних настроек | Не проверено |
| Заблокированный экран / без сети / отмена проверки | Не проверено |
| Зеркальный текст / код / неверный ответ / Enter | Не проверено |
| Клавиатура / крупный шрифт / поворот / аварийное отключение | Не проверено |
| Перемещение кнопки / повторное открытие / лимит переносов | Не проверено |
| Усиление / следующий обычный подъём / микс из шести типов | Не проверено |
| Android: запрос и отзыв администратора | Не проверено |
| Android: батарея / автозапуск / «Не беспокоить» | Не проверено |
| Android: перезагрузка до разблокирования / во время переноса | Не проверено |
| Android: ошибка и повтор восстановления | Не проверено |
| TalkBack/VoiceOver и память без автоматического скрытия | Не проверено |
| iOS: обычная системная остановка | Не проверено |

Запись о полученном событии и зелёный статус разрешений не доказывают слышимый
звук. Результат пробного звонка всегда подтверждает человек.
