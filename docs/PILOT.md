# Пилот 0.2: проверка на телефоне

Автоматические тесты и сборки проверяют код. Доставку звука на конкретном
телефоне проверяет человек. Раздел «Проверка телефона» хранит только последний
ответ пользователя и время проверки; разрешения перепроверяются отдельно.

## Короткий прогон

1. Установить APK на Android 8+ arm64 или собрать приложение на iPhone с
   iOS 26+ и своей подписью. Для обновления поверх 0.1 нужен тот же ключ подписи.
2. Создать будильник с одним переносом и простым заданием. Запомнить время
   основного будильника: пробный звонок не должен его изменить.
3. Открыть «Проверка телефона». Выдавать разрешения по одному; после возврата
   приложение должно показать фактическое состояние каждого разрешения.
4. Запустить пробный звонок, заблокировать телефон и дождаться звука.
   Система должна доставить звонок без открытого экрана Flutter.
5. Пройти задание или воспользоваться аварийным отключением. Вернуться к
   проверке и честно отметить, был ли слышен звук при заблокированном экране.
6. Повторить без сети. Отдельно проверить отмену ожидающей проверки:
   через 20 секунд отменённая проба не должна звонить.
7. Поставить обычный будильник на ближайшие минуты. Использовать перенос,
   закрыть и снова открыть приложение. Бюджет должен оставаться исчерпанным.
8. На Android проверить восстановление после перезагрузки и режим батареи
   производителя. Это отдельные сценарии: один успешный звонок их не доказывает.

## Что записать о результате

Не нужны аккаунт или отправка данных на сервер. Для локального отчёта достаточно:

| Поле | Результат испытания |
|---|---|
| Модель телефона и версия ОС | Заполнить на устройстве |
| Версия приложения и источник APK | 0.2.0; local или GitHub Actions |
| Звонок с заблокированным экраном | Не проверено |
| Звонок без сети | Не проверено |
| Отмена пробного звонка | Не проверено |
| Перенос после закрытия приложения | Не проверено |
| Задание и аварийное отключение | Не проверено |
| Android: перезагрузка и ограничения батареи | Не проверено |

На iOS системная кнопка остановки остаётся доступной в обход задания. На обеих
платформах уведомление приложения о срабатывании не доказывает слышимый звук.
Режим принудительной остановки Android и выключенный телефон — вне гарантий.
