# Ещё пять 0.5.1

Обновления Android теперь доступны через GitHub Releases и Obtainium.

- Один универсальный APK для Android 8+ на ARM, ARM64 и x86-64.
- Подпись совместима с опубликованным пилотом 0.5; package ID сохранён,
  versionCode увеличен до 6. Удалять приложение для обновления не нужно.
- Автоматическая проверка, сборка, подпись и публикация следующих версий по тегу.
- Контрольная сумма и сведения о версии, исходном commit и сертификате рядом с APK.

В Obtainium добавь `https://github.com/Terro216/five-more`.
Репозиторий приватный: сначала укажи в настройках GitHub внутри Obtainium
fine-grained токен только для этого репозитория с **Contents: Read-only**.
[Подробная инструкция](https://github.com/Terro216/five-more/blob/main/docs/OBTAINIUM.md).
Предварительные выпуски включать не требуется.

После обновления проверь сохранённые будильники и выполни «Проверку телефона».
Приложение остаётся пилотом: физическое обновление через Obtainium, доставка
звука и восстановление расписания после установки требуют проверки на устройстве.
iOS-сборка для установки и публикация в магазинах в этот выпуск не входят.
