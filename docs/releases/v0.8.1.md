# Ещё пять 0.8.1

Кандидат для установки со всеми изменениями 0.8.0 и исправлением расчёта
регулярности сна на переводе часов.

- Если перевод часов попал в пользовательский интервал засыпания, время
  укладывания теперь использует смещение часового пояса именно в момент
  укладывания. Это исправляет график режима; длительность сна уже считалась
  по реальному прошедшему времени.
- Добавлена отдельная CI-проверка весеннего и осеннего переходов Europe/Berlin.
- Старые оценки без однозначных локальных метаданных не получают выдуманный
  часовой пояс: их количество видно рядом с графиком. История сохраняется.

[Все изменения 0.8.0](https://github.com/Terro216/five-more/releases/tag/v0.8.0) ·
[Отчёт по реализации и проверкам](https://github.com/Terro216/five-more/blob/v0.8.1/docs/STATUS_0.8.0.md).

Android: **0.8.1 (12)**, прежний пакет и сертификат подписи. APK, контрольная
сумма и происхождение сборки приложены к выпуску.

**На физическом телефоне этот кандидат не проверен.** Обновление с сохранением
данных, звук/приглушение, Bluetooth, вызовы, блокировка, перезагрузка, вибрация
и Bitwarden требуют отдельной проверки. iOS AlarmKit сохраняет системную
остановку без задания; веб остаётся предпросмотром.
