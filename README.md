# Ещё пять · Five More

Будильник с ограниченными переносами и короткими заданиями для пробуждения.
Работает без аккаунта и подключения к интернету. История, оценки сна и
голосовые записи по умолчанию хранятся на телефоне. Можно включить синхронизацию
истории через passkey и ключ восстановления. Загрузка голоса разрешена
только для аккаунта, указанного владельцем сервера, с отдельным согласием.
Новые фразы для заданий можно отдельно
загрузить из интернета по желанию; для звонка сеть не нужна.

## Установка на Android

Скачай APK из [последнего выпуска](https://github.com/Terro216/five-more/releases/latest)
или добавь в Obtainium:

```text
https://github.com/Terro216/five-more
```

Поддерживается Android 8+. Аккаунт GitHub и токен не нужны.
[Инструкция по установке и обновлению](docs/OBTAINIUM.md).

## Возможности

- Обычный звонок или звонок с заданием; необязательное название.
- Быстрый выбор времени с переходом в полные настройки. Переносы, звук и
  вибрация открыты сразу; выбор «С заданием» сразу показывает его параметры.
- Светлая и тёмная темы с сохранением выбора. Для каждого будильника можно
  выбрать своё фото на экран звонка; оно хранится только на телефоне.
- Перенесённый подъём можно открыть и завершить с главного экрана, даже если
  уведомление закрыто. Выключение такого будильника открывает завершение подъёма.
- Общий запас минут для переносов: например, 15 × 1 мин или 3 × 5 мин.
- Режим поиска кнопки переноса среди одинаковых плиток; новое место каждый раз.
- Задания на счёт, память, цвет, порядок чисел, зеркальный текст, код с картинки,
  флаги, зарегистрированный QR-код, тряску и лабиринт с управлением наклоном.
- Несколько уровней сложности, смешанные задания и тренировка до звонка.
- По желанию — усложнение задания после каждого переноса.
- Четыре уровня от «Чилл» до «Нереально», свой порядок заданий в миксе.
- Режим «Вздремнуть», циферблат и ввод времени с прокруткой, перенос со слайдером.
- Мелодия для каждого будильника: встроенные варианты или свой аудиофайл.
  На Android — нарастание 0–60 секунд, отдельная вибрация и временное
  приглушение по 30 секунд дважды на звонок. Системный режим вызова
  приостанавливает мешающие звук и вибрацию, сохраняя будильник.
- Утреннее голосовое до 5 минут с явным продлением и вечернее напоминание.
- Локальный архив SQLite, подгрузка старых событий с сервера, графики за
  выбранный период по всем синхронизированным данным, добровольные оценки сна.
  Повторное открытие истории использует кэш до пяти минут; кнопка обновления
  сразу запрашивает свежие данные.
- Необязательные локальные цели длительности и режима сна.
- Одноразовые будильники можно удалять после отключения, сохраняя историю.
- «Готово» сохраняет и включает; выход назад сохраняет правки без включения.
  Ошибки планирования остаются видимыми.
- Проверка телефона и аварийная остановка с подтверждением и удержанием.
- На Android настоящий звонок не выключается по таймеру. Начавшийся подъём,
  включая перенос, восстанавливается после перезагрузки.
- По желанию — закрытие распознанного меню питания во время звонка через
  отдельное разрешение специальных возможностей Android. Поддержка зависит
  от телефона; принудительную перезагрузку кнопками это не блокирует.

## Перед первым использованием

Открой «Проверку телефона», выдай разрешения и проверь тестовый звонок
с заблокированным экраном. На Android также проверь настройки батареи.
Работа будильника зависит от разрешений и ограничений системы; после
принудительной остановки приложения потребуется открыть его снова.

Исходники iOS рассчитаны на iOS 26+ и AlarmKit. Системная кнопка остановки
остаётся доступной без решения задания. Готовая iOS-сборка пока не распространяется.
Web-сборка позволяет посмотреть интерфейс и потренироваться в заданиях;
фоновые будильники в браузере не поддерживаются.

## Разработка

Приложение написано на Flutter. SDK закреплён в `.flutter-version` и
`.flutter-revision`; для Android нужны JDK 17 и Android SDK, для iOS — macOS
и Xcode 26+.

```sh
bash scripts/bootstrap_flutter.sh /path/to/flutter
export PATH="/path/to/flutter/bin:$PATH"
flutter pub get --enforce-lockfile
flutter run
```
