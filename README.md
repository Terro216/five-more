# Ещё пять · Five More

Будильник с ограниченными переносами и короткими заданиями для пробуждения.
Работает без аккаунта и подключения к интернету. История, оценки сна и
голосовые записи хранятся на телефоне. Новые фразы для заданий можно отдельно
загрузить из интернета по желанию; для звонка сеть не нужна.

## Установка на Android

Скачай APK из [последнего выпуска](https://github.com/Terro216/five-more/releases/latest)
или добавь в Obtainium:

```text
https://github.com/Terro216/five-more
```

Поддерживается Android 8+. Аккаунт GitHub и токен не нужны.
[Инструкция по установке и обновлению](docs/OBTAINIUM.md).

## Возможности

- Быстрые режимы: «Мягко», «С разгоном» и «Без переносов».
- Переносы на 5 или 10 минут с настраиваемым пределом.
- Задания на счёт, память, цвет, порядок чисел, зеркальный текст, код с картинки,
  флаги, зарегистрированный QR-код, тряску и лабиринт с управлением наклоном.
- Несколько уровней сложности, смешанные задания и тренировка до звонка.
- По желанию — усложнение задания после каждого переноса.
- Четыре уровня от «Чилл» до «Нереально», свой порядок заданий в миксе.
- Режим «Вздремнуть», циферблат и ввод времени с прокруткой, перенос со слайдером.
- Мелодия для каждого будильника: встроенные варианты или свой аудиофайл.
- Короткое утреннее голосовое себе и вечернее напоминание его послушать.
- История без лимита в 500 событий, графики и добровольные оценки сна.
- Проверка телефона и аварийная остановка с подтверждением и удержанием.

## Перед первым использованием

Открой «Проверку телефона», выдай разрешения и проверь тестовый звонок
с заблокированным экраном. На Android также проверь настройки батареи.
Работа будильника зависит от разрешений и ограничений системы; после
принудительной остановки приложения потребуется открыть его снова.

Исходники iOS рассчитаны на iOS 26+ и AlarmKit. Системная кнопка остановки
остаётся доступной без решения задания. Готовая iOS-сборка пока не распространяется.
Web-сборка позволяет посмотреть интерфейс и потренироваться в заданиях;
фоновые будильники в браузере не поддерживаются.

## Разработка

Приложение написано на Flutter. SDK закреплён в `.flutter-version` и
`.flutter-revision`; для Android нужны JDK 17 и Android SDK, для iOS — macOS
и Xcode 26+.

```sh
bash scripts/bootstrap_flutter.sh /path/to/flutter
export PATH="/path/to/flutter/bin:$PATH"
flutter pub get --enforce-lockfile
flutter run
```
